## 사진 교체 / 추가

원본은 `imgs/` 에 두고, **`imgs/` 는 `.gitignore` 로 제외돼 있습니다.**
public 레포라서 원본을 커밋하면 원본 해상도가 URL로 공개되고 아래 확대 방지가 무의미해집니다.

1. `imgs/` 에 사진을 넣습니다
2. `build_assets.py` 의 `ORDER` 목록을 수정합니다 (촬영 세트별로 묶여 있습니다)
3. `python build_assets.py` — `assets/` 에 웹용 이미지가 생성됩니다
4. 출력 하단의 `<div class="slide">...` 블록을 `index.html` 의 `#track` 안에 붙여넣고,
   `.slCount` 의 총 장수도 맞춥니다

갤러리는 **슬라이드형**입니다 (신부측 요청: 목록형은 스크롤이 너무 김).
사진을 탭하면 다음 장(왼쪽 30% 탭은 이전 장), 옆으로 밀어도 넘어갑니다.
처음 2장만 즉시 로드하고 나머지는 `data-src` 로 두었다가 현재 위치 앞뒤로 미리 받습니다.
확대는 여전히 차단됩니다 — "넘기기"와 "확대"는 별개입니다.

## 사진 확대 방지

모바일 청첩장 관행대로 사진을 확대할 수 없게 해두었습니다.

- viewport `maximum-scale=1, user-scalable=no`
- `touch-action` — 더블탭 확대 / 핀치 줌 차단
- JS로 iOS `gesture*` 이벤트, 두 손가락 `touchmove`, 더블탭, `ctrl`+휠 취소
  (iOS Safari는 `user-scalable=no` 를 무시하므로 JS가 필요합니다)
- 사진 `pointer-events:none` + `contextmenu` 취소 → 길게 눌러 저장 차단
- 슬라이더는 넘기기만 되고 확대/라이트박스 없음
- 웹용 이미지는 가로 900px로 리사이즈 (원본 비공개)

**한계:** 스크린샷 후 사진 앱에서 확대하는 것은 막을 수 없습니다.
약도는 읽어야 하므로 예외로 두어, 누르면 새 탭에서 크게 볼 수 있습니다.

## 약도 손본 것

업체 PDF를 그대로 쓰지 않고 `build_assets.py` 에서 두 가지를 처리합니다.

1. **아래 교통편 텍스트 블록을 잘라냄** — 폰에서 축소되면 못 읽습니다.
   같은 내용을 `index.html` 에 HTML 텍스트로 넣어두었습니다.
2. **신분당선 색 정정** — 업체 약도는 신분당선을 남색으로 그렸습니다.
   그런데 그 남색은 도보 경로선·핀·"세인트 메리엘" 글자에도 함께 쓰여서,
   색으로만 골라 바꾸면 지도가 통째로 빨개집니다.
   그래서 남색 영역을 연결 요소로 나눈 뒤 역 막대 덩어리(+④번 출구)만 `#A5112F` 로 칠합니다.

> 종이 청첩장 약도는 **여전히 신분당선이 남색**입니다.
