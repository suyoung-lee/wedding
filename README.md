# wedding

이수영 · 이정은 모바일 청첩장.

- **공개 URL:** https://suyoung-lee.github.io/wedding/
- 이 URL은 종이 청첩장 QR코드에 인쇄되므로 **절대 변경 금지** (레포명/브랜치/경로 모두).

## 배포

`main` 브랜치에 push하면 GitHub Pages가 자동 배포합니다. (루트 `/` 서빙)

## 현재 상태

`index.html` 은 뼈대만 있는 placeholder입니다. 노란 배경으로 표시된 부분(`class="todo"`)이
채워야 할 내용이고, 채우면서 `todo` 클래스만 지우면 됩니다.

채워야 할 것:
- [ ] 예식 일시 / 장소 / 주소 / 연락처
- [ ] 인사말 문구
- [ ] 혼주(양가 부모님) 성함
- [ ] 달력 섹션 — 실제 연월로 교체
- [ ] 지도 embed + 길찾기 앱 딥링크 (네이버/카카오/티맵)
- [ ] 사진 (표지 1장 + 갤러리 9장) → `assets/`
- [ ] 계좌번호
- [ ] RSVP 링크 (구글폼 등)
- [ ] `og:` 메타태그 — 카카오톡 공유 미리보기용 제목/설명/이미지(`assets/og.jpg`)

## QR코드

`qr/` 폴더에 인쇄용 QR 파일이 있습니다. 인코딩된 값은 위 공개 URL 그대로입니다.
