## 사진 교체 / 추가

표지는 화면 전체 높이 사진 위에 글자를 얹는 구성이라, **얼굴 위쪽에 여백이 있고 아래쪽이 단조로운 사진**이 맞습니다.
표지 사진은 `build_assets.py` 의 `COVER` 한 줄로 바꿉니다 (카카오톡 미리보기 `og.jpg` 도 같이 재생성됨).

원본은 `imgs/` 에 두고, **`imgs/` 는 `.gitignore` 로 제외돼 있습니다.**
public 레포라서 원본을 커밋하면 원본 해상도가 URL로 공개되고 아래 확대 방지가 무의미해집니다.

1. `imgs/` 에 사진을 넣습니다
2. `build_assets.py` 의 `ORDER` 목록을 수정합니다 (촬영 세트별로 묶여 있습니다)
3. `python build_assets.py` — `assets/` 에 웹용 이미지가 생성됩니다
4. 출력 하단의 `<button class="ph">...` 블록을 `index.html` 의 `#grid` 안에 붙여넣습니다

갤러리는 신부측이 준 레퍼런스(seyoooooung.github.io/wedding-invitation)와 같은 양식입니다:
- 첫 장은 가로 4:3 대표(`assets/wide.jpg`, ORDER 첫 항목 = 유일한 가로 컷), 나머지는 정사각 400px 썸네일 3열
- 처음엔 7장만 보이고 "사진 더보기"로 펼침 (`.grid.collapsed .ph:nth-child(n+8)`)
- 썸네일을 탭하면 어두운 뷰어가 열려 좌우 스와이프·화살표로 넘김, × 또는 배경 탭으로 닫힘
- 뷰어 안에서도 핀치 확대·길게 눌러 저장은 차단됩니다 ("크게 보기"와 "확대"는 별개)
- 지도 버튼도 레퍼런스 규격(52px, 네이버 채움 / 카카오 테두리), 주소 복사는 아래 텍스트 링크

## 사진 확대 방지

모바일 청첩장 관행대로 사진을 확대할 수 없게 해두었습니다.

- viewport `maximum-scale=1, user-scalable=no`
- `touch-action` — 더블탭 확대 / 핀치 줌 차단
- JS로 iOS `gesture*` 이벤트, 두 손가락 `touchmove`, 더블탭, `ctrl`+휠 취소
  (iOS Safari는 `user-scalable=no` 를 무시하므로 JS가 필요합니다)
- 사진 `pointer-events:none` + `contextmenu` 취소 → 길게 눌러 저장 차단
- 뷰어(라이트박스)는 크게 보기만 되고 핀치 확대 없음
- 웹용 이미지는 가로 900px로 리사이즈 (원본 비공개)

**한계:** 스크린샷 후 사진 앱에서 확대하는 것은 막을 수 없습니다.
약도는 읽어야 하므로 예외로 두어, 누르면 새 탭에서 크게 볼 수 있습니다.

## 약도 손본 것

업체 PDF를 그대로 쓰지 않고 `build_assets.py` 에서 두 가지를 처리합니다.

1. **아래 교통편 텍스트 블록을 잘라냄** — 폰에서 축소되면 못 읽습니다.
   같은 내용을 `index.html` 에 HTML 텍스트로 넣어두었습니다.
2. **신분당선 색 정정** — 업체 약도는 신분당선을 남색으로 그렸습니다.
   그런데 그 남색은 도보 경로선·핀·"세인트 메리엘" 글자에도 함께 쓰여서,
   색으로만 골라 바꾸면 지도가 통째로 빨개집니다.
   그래서 남색 영역을 연결 요소로 나눈 뒤 역 막대 덩어리(+④번 출구)만 `#A5112F` 로 칠합니다.

> 종이 청첩장 약도는 **여전히 신분당선이 남색**입니다.
> 주문서의 "약도 수정 요청" 란에 따로 요청하지 않으면 인쇄본은 그대로 나갑니다.

## 배치안 비교

사진 순서/표지를 비교해 보려고 만든 미리보기입니다. 하객에게 공유하는 건
루트 URL 하나뿐이고, 아래 경로는 두 분이 고르실 때만 씁니다.

| | 경로 | 표지 | 앞부분 순서 |
|---|---|---|---|
| A (운영) | `/` | 아치 · 부케로 얼굴 가린 컷 | 5 아치 두 사람 · 6 머메이드 · 7 케이크 · 8 아이보리 신랑 |
| B (미리보기) | `/alt/` | 아치 · 마주 본 컷 | 5 케이크 · 6 머메이드 · 7 아이보리 신랑 · 8 아이보리 두 사람 |
| C (미리보기) | `/alt2/` | **스크롤하면 꽃이 걷히며 얼굴이 드러남** | B 와 동일 |

C 의 표지는 두 장을 겹쳐 두고, 위에 얹은 "꽃으로 가린 컷"의 투명도를
스크롤에 따라 내립니다. 얼굴이 화면 위로 사라지는 지점(표지 높이 820px
기준 약 469px)의 60% 인 281px 에서 전환이 끝나도록 잡아, 드러난 얼굴을
충분히 보고 지나가게 했습니다. 표지 높이가 달라지면 이 값도 같이 계산됩니다.
"동작 줄이기"를 켠 기기에서는 전환 없이 꽃으로 가린 컷만 보입니다.

`alt/index.html` 은 `index.html` 에서 **표지와 그리드만** 바꾼 사본입니다.
사진은 `../assets/` 를 그대로 참조하고, B 에만 있는 것(표지, 되살린 아이보리
두 사람 컷)만 `alt/assets/` 에 둡니다 — 용량이 두 배로 늘지 않게.

`<meta name="robots" content="noindex">` 를 넣어 검색에 잡히지 않게 했습니다.
정하고 나면 `alt/` 는 지우면 됩니다.
